## 面试复习方式

- 先看"面试常见问法"，明确这个知识点会怎么被问。
- 再背"核心回答"，形成 1 到 3 分钟的口述框架。
- 然后看"项目结合"和代码示例，把答案落到 Java 后端项目经验。
- 最后看"深入追问"和"常见问题"，准备面试官继续深挖。

## 学习路径建议

```
JVM 内存区域 → 对象创建与内存布局 → 垃圾回收机制 → 垃圾收集器 → JVM 调优实践
                                                                ↑
                                                          类加载机制
JMM → 字节码与执行引擎 → JIT编译与逃逸分析
OOM分类与排查 → GC日志分析实战 → Safepoint与STW → 直接内存与堆外内存
```

1. 先理解 JVM 内存区域的划分，这是所有后续概念的基础。
2. 再了解对象是如何创建和在内存中布局的。
3. 然后学习垃圾回收的判定算法和回收算法。
4. 在此基础上认识各种垃圾收集器及其适用场景。
5. 最后结合调优实践，把理论落到线上问题排查和参数调整。
6. 类加载机制相对独立，可以穿插学习。
7. JMM、字节码、JIT、Safepoint 和堆外内存适合用于准备资深面试中的深入追问。

## 写作约定

- 每篇只讨论一个概念，关联知识只做必要引用。
- 必须结合 Java 后端真实场景，例如线上 OOM 排查、GC 调优、类加载冲突、内存泄漏定位。
- 涉及代码时，关键逻辑必须使用简体中文注释。
- 涉及内存结构、GC 流程、类加载过程时，优先使用 Mermaid 辅助说明。
